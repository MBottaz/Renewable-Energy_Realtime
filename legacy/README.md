# Legacy scripts

These scripts are from v0.1 of the project, focused on Italy-only analysis with Matplotlib visualizations. They have been replaced by the `energy-scenarios/` frontend.

| Script | Description | Replaced by |
|--------|-------------|-------------|
| `import_API.py` | Fetch ENTSO-E data as CSV | `energy-scenarios/fetch_data.py` |
| `EnergyMatch.py` | Bar chart visualization | `energy-scenarios/app.js` (Chart.js) |
| `energy_system_simulation.py` | Capacity scaling simulation | `energy-scenarios/app.js` (frontend scaling) |
